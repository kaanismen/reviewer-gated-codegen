# docs/gorseller/

Belgelerde kullanılan ekran görüntüleri. Dosya adları `README.md` ve
`docs/kilavuz.md` içinden referans veriliyor; **adları değiştirmeyin.**

| Dosya | İçerik | Nerede kullanılıyor |
|---|---|---|
| `agent-hatti.png` | Agent hattı — bir agent çalışırken (nabız + süre görünür) | README, kılavuz §4 |
| `red-revizyon.png` | Transkript ayrıntısı — RED turu ve revizyon görünür | README |
| `oyun.png` | Üretilmiş bir oyun oynanırken | README, kılavuz §5 |
| `kapsam-disi.png` | Satranç transkripti — `KAPSAM_DISI` ve gerekçesi | README, kılavuz §6 |
| `ayarlar.png` | Ayarlar paneli — üç rol, model kataloğu, limitler | kılavuz §3 |
| `acilis.png` | Açılış ekranı — görev kutusu ve üretilen oyunlar | kılavuz §1 |

## Öneriler

- Tarayıcı yakınlaştırması **%100**; metin okunabilir olmalı.
- Genişlik ~900–1000 px yeterli; daha genişi belgede küçülür.
- PNG tercih edin (metin keskin kalır).
- Kişisel bilgi içermemeli — anahtar maskeleri (`••••Pu4A`) sorun değil,
  ama tarayıcı sekmeleri ve yer imleri kadraja girmesin.
